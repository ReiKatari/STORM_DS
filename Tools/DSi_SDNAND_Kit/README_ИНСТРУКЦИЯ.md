# 🎮 Полный инструментарий и инструкция по созданию расширенного SD-NAND (HiyaCFW + TWiLight Menu++) для STORM DS

Данный набор инструментов позволяет создать образ виртуальной SD-карты любого размера (2 ГБ, 4 ГБ, 8 ГБ, 16 ГБ), на которую можно записать **всю мировую библиотеку DSiWare (400+ игр)**, все **русские версии**, Homebrew и классические NDS игры без ограничений системного меню DSi.

---

## 📁 Структура каталога `E:\STORM DS\Tools\DSi_SDNAND_Kit`

- `1_HiyaCFW_Helper\` — Автоматический мастер создания SD-NAND из чистого `nand.bin` (v3.6.10, `HiyaCFW-Helper.exe`).
- `2_TWiLightMenu_DSi\` — Новейшая оболочка TWiLight Menu++ (v27.24.1: папки `_nds`, `roms`, `title`, файл `BOOT.NDS`).
- `3_GodMode9i\` — Полнофункциональный DSi файловый менеджер (v3.9.0, `GodMode9i.nds`).
- `4_ninfs_NAND_Mounter\` — Утилита монтирования `nand.bin` как локального диска в Windows (v2.0, `ninfs.exe`).
- `5_Unlaunch\` — Кастомный загрузчик DSi (v2.0, `UNLAUNCH.DSI`).

---

## 🛠️ Пошаговая инструкция по сборке

### Шаг 1: Создание SD-NAND через HiyaCFW-Helper
1. Запустите `1_HiyaCFW_Helper\HiyaCFW-Helper.exe`.
2. Выберите ваш исходный дамп `nand.bin` (от DSi).
3. Укажите целевую папку для распаковки файловой структуры SD-карты.
4. Программа автоматически расшифрует разделы, применит патчи Unlaunch / HiyaCFW и подготовит готовую файловую структуру.

### Шаг 2: Установка TWiLight Menu++
1. Скопируйте папки `_nds`, `roms`, `title` и файл `BOOT.NDS` из `2_TWiLightMenu_DSi\` в корень созданной виртуальной SD-карты (с заменой файлов).
2. Поместите все ваши DSiWare `.nds` / `.dsi` игры (оригиналы и русские версии) в папку `roms/dsiware/` или `roms/nds/`.

### Шаг 3: Подключение к STORM DS
1. В STORM DS откройте **«Настройки ➔ Система и BIOS ➔ Настройки SD-карты DSi»**.
2. Включите **«Использовать SD-карту DSi»** и укажите путь к сформированному образу или папке синхронизации.
3. В **«Тип консоли»** выберите **Nintendo DSi**.
4. При запуске прошивки DSi эмулятор сразу запустит **TWiLight Menu++** со всей библиотекой ваших игр без ограничений!
